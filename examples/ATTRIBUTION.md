# Example images

These 3 images come from the test split of the **Drug Name Detection** dataset
by P. Karimi Darabi (origin: Roboflow, Kabul University), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Dataset: https://www.kaggle.com/datasets/pkdarabi/the-drug-name-detection-dataset

Changes: drawn at random (seed 42, `tools/make_examples.py`), resized
(longest side <= 1024 px), re-encoded as JPEG (quality 90), metadata removed.
